Q1 – Spot the Invalid Addresses

Admission PC: 172.16.45.200/20 -> network 172.16.32.0, broadcast 172.16.47.255, valid host.
Lab printer: 10.0.15.255/21 -> network 10.0.8.0, broadcast 10.0.15.255, INVALID broadcast.
X-ray server: 192.168.4.0/23 -> network 192.168.4.0, broadcast 192.168.5.255, INVALID network address.
Clinic router: 203.0.113.10/29 -> network 203.0.113.8, broadcast 203.0.113.15, valid host.

NAT/PAT example:
PC-A 192.168.1.10:50000 -> 203.0.113.10:50000
PC-B 192.168.1.11:50000 -> 203.0.113.10:50001

Datagram switching allows packets to take different paths and arrive out of order. Virtual circuits establish a logical path first.
A public /27 has 30 usable addresses, enough for 18 devices, but exposes more hosts and reduces NAT-related application issues.
